# Скриншотные тесты

Playwright запускает настоящий портал с отдельной временной SQLite и вымышленными аккаунтами. Рабочий сервер и его данные не используются. Требуются зависимости Python из основного README и зависимости из `portal/requirements.txt`.

```bash
cd tests/ui
npm ci --ignore-scripts
npx playwright install chromium --only-shell
PYTHON=/path/to/venv/bin/python npm test
```

Проверяются страницы входа, пользователей, RU-выходов, маршрутизации устройств и кабинета с разными правами на 360×800, 390×844, 768×1024 и 1440×1000. Для 390×844 есть тёмная тема. Тесты сравнивают полные снимки, проверяют отсутствие горизонтального переполнения, красную активную вкладку, `formaction`, выход после AJAX-сохранения, порядок кнопок и загрузку файла, повторное редактирование сохранённого конфига и hover выбора страны внутри границ телефонного поля. Дополнительно проверяются единое сохранение имени и выхода, расположение полей в строку, отступ шеврона и клавиатурный focus. Общие правила — [DESIGN.md](../../DESIGN.md). Все ключи на снимках тестовые.

Эталоны в `layout.spec.cjs-snapshots/` сняты Chromium на macOS. На другой ОС создайте отдельные эталоны и просмотрите их: шрифты платформ отличаются. Для намеренного изменения дизайна: `npm run test:update`, визуальный просмотр PNG, затем обычный `npm test` без обновления эталонов. Не принимайте новые снимки автоматически при падении теста. Отчёт: `npx playwright show-report`.

Дополнительно проверяются роли, каталог способов входа, безопасность профиля и правила устройства. Виртуальный FIDO2-аутентификатор проверяет регистрацию, подтверждение, повтор ответа и удаление ключа. Тесты используют только локальные данные.
