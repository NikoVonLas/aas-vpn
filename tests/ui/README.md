# Скриншотные тесты

Playwright запускает настоящий портал с отдельной временной SQLite и вымышленными аккаунтами. Рабочий сервер и его данные не используются. Требуются зависимости Python из основного README и `npm ci --ignore-scripts --prefix portal`.

```bash
cd tests/ui
npm ci --ignore-scripts
npx playwright install chromium --only-shell
PYTHON=/path/to/venv/bin/python npm test
```

Проверяются страницы входа, пользователей, RU-выходов, маршрутизации и устройств на 360×800, 390×844, 768×1024 и 1440×1000. Для 390×844 есть тёмная тема. Тесты сравнивают полные снимки, проверяют отсутствие горизонтального переполнения, красную активную вкладку, `formaction`, выход после AJAX-сохранения, порядок кнопок и загрузку файла с редактированием текста перед отправкой.

Эталоны в `layout.spec.cjs-snapshots/` сняты Chromium на macOS. На другой ОС создайте отдельные эталоны и просмотрите их: шрифты платформ отличаются. Для намеренного изменения дизайна: `npm run test:update`, визуальный просмотр PNG, затем обычный `npm test` без обновления эталонов. Не принимайте новые снимки автоматически при падении теста. Отчёт: `npx playwright show-report`.
