# Проверки интерфейса

Playwright запускает настоящий портал с временными базами, тестовыми аккаунтами и локальным HTTPS-сертификатом. Проверка сертификата отключена только для этого тестового origin: WebKit требует HTTPS для защищённых cookie. Провайдеры и VPN API изолированы от рабочего сервера.

```bash
cd tests/ui
npm ci --ignore-scripts
npx playwright install chromium firefox webkit
PYTHON=/path/to/venv/bin/python npm test
```

Chromium сравнивает снимки на 360×800, 390×844, 768×1024 и 1440×1000 в светлой и тёмной темах. Реестр `screens.json` связывает шаблоны со сценариями; `test_views.py` запрещает новые страницы без решения о покрытии. Каталог настоящих компонентов доступен только на стенде: `/fixture/components`.

Проверяются основные страницы и раскрытые редакторы, все 16 наборов способов входа, автоопределение и заполненный пароль, ошибки, ограниченный вход, настройка аутентификатора, восстановление и резервные коды, диалоги, лимиты и состояния маршрутизатора. Функциональные сценарии восстановления, возврата фокуса, ошибок входа и возвращения черновика запускаются также Firefox и WebKit. Виртуальный FIDO2 остаётся в Chromium. Есть проверки контраста темы и переполнения при увеличенном тексте.

После намеренного изменения дизайна: `npm run test:update`, ручной просмотр PNG, затем `npm test` без обновления эталонов. Эталоны macOS хранятся в `*-snapshots/`; для другой ОС нужны собственные проверенные эталоны. Динамические одноразовые коды заменяются фиксированным тестовым текстом только в снимках; сквозной функциональный тест использует настоящий выпущенный код. Отчёт: `npx playwright show-report`.

Обязательны также `./scripts/validate.sh --tests` и свежий SonarQube для коммита. Правила компонентов: [DESIGN.md](../../DESIGN.md).
